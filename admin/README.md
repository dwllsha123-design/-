# دار الأنوثة — Admin Dashboard

واجهة إدارة عربية RTL مربوطة بالـ Central API.

## التشغيل

```bash
cd admin
npm install
npm run dev
```

يفتح على `http://localhost:5173` ويوجّه `/api` إلى الباكند على المنفذ 3000.

## الصفحات

- لوحة التحكم
- الطلبات + إنشاء طلب فيسبوك
- المنتجات
- العملاء
- المخزون
- صفحات فيسبوك
- التوصيل
- نقطة البيع (POS)
